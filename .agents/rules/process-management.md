# 開発・プロセス＆音声再生の管理ルール

1. **音声生成エラーの事前点検とマッピング徹底**:
   - 注音符号や単語例の音声再生機能を実装・変更する際は、注音記号単体（例: `ㄚ`, `ㄛ`, `ㄜ`, `ㄝ`, `ㄞ`, `ㄟ` など）や異体字によって Google TTS / Web Speech API 側で「音声生成エラー（無音・エラーレスポンス）」が発生しないか必ず確認すること。
   - TTS エンジンが100%確実に標準台湾華語（`zh-TW`）として音声を生成・再生できる安定した発話テキスト（`ZHUYIN_SPEECH_MAP`）を常時維持・更新すること。

2. **重複プロセスの禁止**:
   - `npm run dev` などの開発サーバーやバックグラウンドプロセスを起動する際は、すでに同一プロジェクトのサーバーが起動していないか確認する。
   - コード修正やレイアウト変更後に新しい開発サーバーを起動する場合は、古いバックグラウンドタスク（`manage_task`）を必ず先に停止 (kill) してから起動すること。

3. **バックグラウンドタスクのクリーンアップ**:
   - バックグラウンドでプロセスを立ち上げたまま放置せず、不要になったプロセスはすみやかに `manage_task` を用いて整理・停止すること。
