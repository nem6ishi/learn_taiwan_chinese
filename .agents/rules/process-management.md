# バックグラウンドプロセス・開発サーバーの管理ルール

1. **重複プロセスの禁止**:
   - `npm run dev` などの開発サーバーやバックグラウンドプロセスを起動する際は、すでに同一プロジェクトのサーバーが起動していないか確認する。
   - コード修正やレイアウト変更後に新しい開発サーバーを起動する場合は、古いバックグラウンドタスク（`manage_task`）を必ず先に停止 (kill) してから起動すること。

2. **バックグラウンドタスクのクリーンアップ**:
   - バックグラウンドでプロセスを立ち上げたまま放置せず、不要になったプロセスはすみやかに `manage_task` を用いて整理・停止すること。
